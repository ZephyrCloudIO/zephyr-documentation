# Personal token deployments

Personal tokens work today, including for deployments that set `ZE_SECRET_TOKEN`.

:::info Planned for deprecation
Using personal tokens for deployments is planned for deprecation. No removal date has been announced.

For deployments, we recommend [CI tokens](/features/ci-tokens) (`ZE_CI_TOKEN`). Personal tokens remain available for user-scoped access where the product supports it.
:::

## Move deployments to CI tokens

Follow the [deployment auth migration guide](/migrations/ci-token-migration) to replace `ZE_SECRET_TOKEN` with `ZE_CI_TOKEN`.
