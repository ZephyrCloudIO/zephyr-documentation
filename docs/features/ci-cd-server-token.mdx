# Server token deployments

Server tokens authenticate Zephyr plugins at the organization level. They work today, including for CI deployments that set `ZE_SERVER_TOKEN` and `ZE_USER_EMAIL`.

:::info Planned for deprecation
Using server tokens for deployments is planned for deprecation. No removal date has been announced.

For new and existing pipelines, we recommend [CI tokens](/features/ci-tokens) (`ZE_CI_TOKEN`). The [migration guide](/migrations/ci-token-migration) lists the variables to replace.
:::

## Generate a server token

1. Go to **Organization Settings** in Zephyr Cloud.
2. Open **Server Tokens**.
3. Click **Generate token**, then copy the value. It is shown only once.

## Security notes

- Do not share server tokens publicly.
- Server tokens grant organization-level access. Rotate them regularly, and revoke any that may be compromised.
