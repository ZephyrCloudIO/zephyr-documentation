<ErrorInfo code="ZE20039" terminal related="ZE20040" />

Zephyr build retention removes files from your edge provider when no remaining build uses them. When a new build references one of those files, the edge rejects the snapshot upload and lists the missing files. The Zephyr plugin then re-uploads them and retries the snapshot upload up to three times, a few seconds apart.

This error means the edge still reported files as missing after those retries.

## Debugging the error

<Steps>

### Rebuild your application

Wait a minute, then run your build again. The plugin has already dropped the missing files from its local list of uploaded files, so the next build uploads them again.

```bash
npm run build
```

### Contact support if it persists

If the error comes back after a rebuild, [contact us on Discord](https://discord.gg/zephyrcloud) with the build id and the full error output.

</Steps>
