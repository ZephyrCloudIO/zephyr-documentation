<ErrorInfo code="ZE20040" terminal related="ZE20039" />

Zephyr build retention removes files from your edge provider when no remaining build uses them. When a new build references one of those files, the edge rejects the snapshot upload and lists the missing files, and the Zephyr plugin re-uploads them.

This error means some of the missing files are not part of the current build output, so the plugin cannot re-upload them.

## Debugging the error

<Steps>

### Rebuild without the cache

Clear your bundler's build cache (for example `node_modules/.cache`) and any build cache your CI restores, then run a full build.

```bash
npm run build
```

### Contact support if it persists

If the error comes back after a clean build, [contact us on Discord](https://discord.gg/zephyrcloud) with the build id and the full error output.

</Steps>
