Zephyr answered a request with an HTTP error status that a retry will not fix, such as `400`, `404` or `409`. The message shows the method, the URL with query values redacted, the status code, and the response.

Other failures have their own codes:

- Network errors, DNS failures, timeouts, and HTTP 5xx or 408 responses: [ZE50001](/errors/ze50001).
- HTTP 401: [ZE10018](/errors/ze10018).
- HTTP 403: [ZE10022](/errors/ze10022).

Older plugin versions also reported network errors and 5xx responses as `ZE40035`, with the advice to check your network connection. If you see that advice, follow [ZE50001](/errors/ze50001).

## Debugging the error

<Steps>

### Read the status code and the response

The response usually says which value Zephyr rejected. A `404` can mean that Zephyr does not know the application, version, tag, or environment in the request.

### Wait on HTTP 429

`429` means too many requests. Wait, then run the build again.

### Update the Zephyr plugin

Make sure you use the latest version of your Zephyr plugin.

</Steps>
