Zephyr checks the local build output before it uploads it. This error means it found a problem and did not deploy the build. The line after `Failed to deploy local build.` names the problem.

## Common causes

### The compilation has errors

`Zephyr will not upload ... output because the compilation contains errors.` Fix the build errors first. Zephyr does not deploy a failed compilation.

### `ze-cli run` could not detect the output directory

`ze-cli run` reads your build configuration to find the output directory. When the configuration is too dynamic to read, `ze-cli run` builds your project, skips the upload, and exits with code 1. Upload the output yourself:

```bash
ze-cli deploy ./dist
```

You can also use the Zephyr plugin for your bundler instead of `ze-cli run`.

### An output path or entrypoint is missing or outside the output directory

The message names the path. Check the output directory and the entrypoint in your build configuration.

### Module Federation metadata is invalid or conflicting

The message names the remote or the field. Make sure every Module Federation name and filename is unique, and that every configuration declares the same values for the same remote.

### A multi-compiler or multi-environment build is incomplete

Zephyr deploys a coordinated build only when every compiler or environment produces its output. The message names the one that did not.
